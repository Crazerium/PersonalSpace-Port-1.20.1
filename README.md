# Personal Space: Unofficial 1.20.1 Port

**Personal Space: Unofficial 1.20.1 Port** is a Forge port of the original Personal Space mod for Minecraft 1.20.1.

The mod allows players to create and enter their own personal dimensions. These dimensions can be configured with custom blocks, biome settings, time, weather, boundaries, gaps, and other world options.

> This is an unofficial port. It is not an official continuation of the original Personal Space mod.

## Features

* Create personal player-owned dimensions.
* Configure the dimension floor, wall, roof, boundary, and gap blocks.
* Configure dimension size, height, time of day, weather, and biome.
* Personal portal block for entering and leaving the dimension.
* Server-side validation for dimension creation settings.
* Optional GTCEu compatibility for GT Odyssey / GTCEu bedrock fluid veins.
* Forge 1.20.1 support.

## Requirements

* Minecraft 1.20.1
* Forge 47.x
* Infiniverse

## Optional Compatibility

### GTCEu / GT Odyssey

If GTCEu is installed, Personal Space can add Personal Space dimensions to matching GTCEu/GTO bedrock fluid veins.

This compatibility is optional. The mod should still load and work without GTCEu installed.
